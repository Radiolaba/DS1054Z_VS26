Он состоит из основного исходного файла DS1054Z_VS26.cpp, в котором отражена последовательность производимых операций: команда создания объекта осциллографа, команда подключения осциллографа (команду отключения пока реализовывать не нужно), команда настройки осциллографа и записи данных в 2 текстовых файла.

Есть исходный файл Oscill.cpp, в котором описывается все взаимодействие с осциллографом через класс. В данном файле возможно остались куски кода от работы с другим осциллографом. При этом используемый осциллограф выдает данные 8 бит. Вот как это описывается в programming guide: "If an digital channel (D0 to D15) is selected, the :WAVeform:DATA? command always
returns the waveform data in BYTE format. If the waveform data on the screen is
read, the signal status of the channel source currently selected is returned and a
waveform point occupies one byte (8 bits)" (номер доумента, по которому можно найти его PDF в сети: PGA19108-1110). Данному файлу соответствует заголовочный файл с тем же названием.

Есть исходный файл math.cpp, в котором есть описание функции для преобразования вектора с данными по типу данных. Данному файлу соответствует заголовочный файл с тем же названием.

Есть исходный файл files.cpp, в котором есть описание функции для записи в текстовый файл.
Данному файлу соответствует заголовочный файл с тем же названием.
